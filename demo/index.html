What this page does (the host's job)

The picker never fetches. This page loads the raw endpoint JSON from ./models/, assigns each to its window global, and — like the production backend — enriches NVIDIA from the OpenRouter catalog (same ids) and forces its pricing free. Then it calls ModelSelectorModal.open({ … }) and reads back onSelect(id, modelObj, api). View source for all of it.
